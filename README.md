# Sistema de Gestão de Vendas e Comissões

## Sobre o projeto
Desenvolvi este projeto em Python para praticar lógica de programação e cálculos matemáticos aplicados a situações comerciais.

Minha ideia foi criar um sistema simples que simulasse o registro de vendas de uma empresa, permitindo calcular comissões de vendedores e acompanhar os resultados das operações.

## Funcionalidades
- Registrar vendas.
- Informar o nome do vendedor.
- Calcular comissões com base em percentuais.
- Consultar o faturamento total.
- Consultar o total de comissões.
- Verificar a quantidade de vendas realizadas.

## Conhecimentos utilizados
Python, variáveis, operações matemáticas, cálculos percentuais, estruturas condicionais (`if`, `elif`, `else`) e laços de repetição (`while`).

## Como executar
Execute o arquivo Python do projeto em um ambiente com Python 3 instalado.

**Observação:** Projeto acadêmico de prática em programação, com armazenamento temporário das informações durante a execução.
